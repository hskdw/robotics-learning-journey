## About This Repository

This repository documents my systematic journey from programming fundamentals to robotics and automation projects.

My goal is to build practical skills through continuous learning, simulation, experiments, and project development.

The focus areas include:

- Python programming
- Industrial automation and PLC fundamentals
- Machine vision with OpenCV
- Robotics fundamentals and simulation
- ROS 2 and mobile robotics

This is a learning-in-public project. Notes, code, experiments, and improvements will be added progressively.

## Learning Principles

1. Learn the fundamentals before moving to complex tools.
2. Build small projects instead of only watching tutorials.
3. Document problems, solutions, and lessons learned.
4. Prefer reproducible experiments and clear code.
5. Use simulation and safe, low-voltage educational setups when appropriate.
